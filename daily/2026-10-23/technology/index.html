Canva Launches Craft, Its First In-House Image Generation Model, Which Plans Before It Generates

Canva发布首个自研图像生成模型Craft，先规划再生成

10月23日 05:51重要可靠性 B

Canva于10月22日发布其首个自研AI图像生成模型Canva Craft。据The Verge报道，该模型采用两阶段架构，先生成设计方案再生成图像，Canva称这带来“更高的精确度、一致性和控制力”。模型支持最高2K分辨率和30多种宽高比，可用于社交媒体内容、营销素材、写实场景和数字艺术等，并声称能更准确地生成需要清晰文字和精确物体位置的复杂图像。

Canva称Craft使用平台内容库中“数百万份人工制作的模板”训练。在众包基准Design Arena的图像生成模型排行榜上，该模型目前位列第四，落后于OpenAI的GPT-Image-2.5 Sunburst、GPT-Image-2.5 Flare和GPT-Image-2。Canva Craft已向全球所有用户开放，入口在Canva左侧菜单的Dream Lab。

Canva released Canva Craft, its first in-house AI image generation model, on October 22. According to The Verge, the model uses a two-stage architecture that first generates a design plan and then generates the image, which Canva says brings "greater precision, consistency, and control." The model supports resolutions up to 2K and more than 30 aspect ratios, and can be used for social media content, marketing materials, photorealistic scenes, and digital art, among other things, and it is claimed to generate complex images that require clear text and precise object placement more accurately.

Canva says Craft was trained on "millions of human-made templates" in the platform's content library. On the crowdsourced Design Arena image generation model leaderboard, the model currently ranks fourth, behind OpenAI's GPT-Image-2.5 Sunburst, GPT-Image-2.5 Flare, and GPT-Image-2. Canva Craft is now available to all users worldwide, accessible through Dream Lab in Canva's left-hand menu.

MiniMax Releases Code Mini App, With Agent Applications Running Permanently as Plugins

MiniMax发布Code Mini App，Agent应用以插件形式常驻运行

10月22日 14:32重要可靠性 A

MiniMax于10月22日发布MiniMax Code Mini App。据其博客介绍，Mini App是一种带前端和后端、可以长期运行的应用，以插件形式安装，能与Agent互相调用，让Agent的工作留在一个持续运行的页面上。它兼容MiniMax Plugin协议，包含miniapp.json声明、前端页面和Node.js服务端，由宿主负责端口、鉴权、凭证和可回滚发布。

此次发布包括Mini App运行时、可通过一句话把需求做成页面的/miniapp-creator，以及插件市场中的官方Mini App和开源社区仓库MiniMax-Code-MiniApps。首批官方应用包括股票信息看板、3D模型查看器和自驾规划工作台。MiniMax称Mini App代码以用户身份在本机运行，账号凭证由宿主保管，插件和页面无法获取，并提醒只安装来源可信的包。该功能现已在MiniMax Code桌面端macOS和Windows的本地会话中可用。

MiniMax released the MiniMax Code Mini App on October 22. According to its blog, a Mini App is an application with both a front end and a back end that can run over the long term; it is installed as a plugin and can call and be called by the Agent, keeping the Agent's work on a continuously running page. It is compatible with the MiniMax Plugin protocol and includes a miniapp.json declaration, front-end pages and a Node.js server, while the host handles ports, authentication, credentials and rollback-capable releases.

This release includes the Mini App runtime, /miniapp-creator, which can turn a requirement into a page in a single sentence, as well as official Mini Apps in the plugin marketplace and the open-source community repository MiniMax-Code-MiniApps. The first batch of official applications includes a stock information dashboard, a 3D model viewer and a road-trip planning workbench. MiniMax says Mini App code runs locally under the user's identity, account credentials are kept by the host and cannot be accessed by plugins or pages, and it reminds users to install only packages from trusted sources. The feature is now available in local sessions of the MiniMax Code desktop app on macOS and Windows.

China Telecom's Xingchen Lab releases and open-sources intent-understanding model Xing4.0-29B-Intent

中电信星辰实验室发布并开源意图理解专用模型Xing4.0-29B-Intent

10月22日 15:11重要可靠性 B

中电信人工智能科技有限公司星辰通用人工智能实验室发布并开源意图理解专用模型Xing4.0-29B-Intent，同步开放275.3万条监督微调训练语料、模型权重与推理镜像。模型基于星辰通用基座Xing4.0-29B-A4B微调，把意图识别与参数抽取结合，将用户一句话转换为业务系统可处理的结构化JSON信息，代码采用Apache 2.0许可。据量子位文章，该模型已在电信万号客服、智能家居音箱等场景应用。

技术团队公布的评测显示，在48个中英文公开数据集抽取的6000道题上，该模型总分为58，高于其参评的18款通用模型中最高总分49。第二组5606道类别判断题中，其总决策分为70，对比模型Jev为56、GPT-6-Luna为65。文章注明上述评测由该公司技术团队开展，反映本次数据和测试设置下的表现，不代表所有任务和实际部署场景。

The Xingchen Artificial General Intelligence Lab of China Telecom Artificial Intelligence Technology Co., Ltd. has released and open-sourced the intent-understanding dedicated model Xing4.0-29B-Intent, simultaneously opening 2.753 million supervised fine-tuning training corpus entries, the model weights and the inference image. The model is fine-tuned on the Xingchen general base model Xing4.0-29B-A4B, combines intent recognition with parameter extraction, and converts a user's single sentence into structured JSON information that business systems can process, with the code under the Apache 2.0 license. According to an article by QbitAI, the model has been applied in scenarios such as telecom ten-thousand-number customer service and smart home speakers.

中电信人工智能科技有限公司星辰通用人工智能实验室发布并开源意图理解专用模型Xing4.0-29B-Intent，同步开放275.3万条监督微调训练语料、模型权重与推理镜像。模型基于星辰通用基座Xing4.0-29B-A4B微调，把意图识别与参数抽取结合，将用户一句话转换为业务系统可处理的结构化JSON信息，代码采用Apache 2.0许可。据量子位文章，该模型已在电信万号客服、智能家居音箱等场景应用。

An evaluation published by the technical team shows that on 6,000 questions extracted from 48 Chinese and English public datasets, the model scored 58 in total, higher than the highest total score of 49 among the 18 general models it was evaluated against. In a second set of 5,606 category judgment questions, its total decision score was 70, compared with 56 for the comparison model Jev and 65 for GPT-6-Luna. The article notes that the above evaluation was conducted by the company's technical team, reflects performance under this data and test setup, and does not represent performance on all tasks and in actual deployment scenarios.

NVIDIA Launches Minerva Platform, Bringing End-to-End Observability to AI Factories

NVIDIA发布Minerva平台，面向AI工厂提供端到端可观测性

10月22日 23:00重要可靠性 A

NVIDIA于10月22日发布AIOps平台Minerva，用于帮助团队更早发现问题并维持AI工厂产出。该平台汇集NVIDIA GPU、网络、存储、调度器和工作负载的遥测数据，构建动态知识图谱，映射GPU、SuperNIC、交换机和线缆以及其上运行的任务，并称可每小时分析数十亿数据点，学习正常行为、检测异常、预测故障并关联相关事件。

Minerva提供原生AI助手并可连接外部智能体工具，操作员可通过对话查询集群健康状况并获得修复建议，也可保持人工确认后手动执行或接入自动化。NVIDIA称，IREN、Aolani、Bitdeer AI、IBM、Jio、Lambda、Quake AI和Tesla计划部署Minerva，Dell Technologies、Lenovo和Supermicro将把Minerva纳入其AI工厂运营产品。相关效果均为NVIDIA官方描述，未提供独立测试数据。

On October 22, NVIDIA released Minerva, an AIOps platform designed to help teams detect problems earlier and sustain AI factory output. The platform aggregates telemetry data from NVIDIA GPUs, networks, storage, schedulers, and workloads to build a dynamic knowledge graph that maps GPUs, SuperNICs, switches, and cables along with the jobs running on them, and it claims to analyze billions of data points per hour, learn normal behavior, detect anomalies, predict failures, and correlate related events.

Minerva provides a native AI assistant and can connect to external agent tools, allowing operators to query cluster health through conversation and receive remediation suggestions, while also keeping manual execution after human confirmation or integrating with automation. NVIDIA said IREN, Aolani, Bitdeer AI, IBM, Jio, Lambda, Quake AI, and Tesla plan to deploy Minerva, and that Dell Technologies, Lenovo, and Supermicro will incorporate Minerva into their AI factory operations offerings.
