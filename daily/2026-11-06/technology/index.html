Baidu Open-Sources ERNIE 5.5 Flash Base, a 280-Billion-Parameter MoE Model

百度开源文心5.5 Flash Base，MoE 总参数2800亿

11月05日 15:15重要可靠性 B

据量子位报道，百度11月5日在 Hugging Face 开源基座模型文心5.5 Flash Base（ERNIE 5.5 Flash Base）。模型采用 MoE 架构，总参数2800亿，每个 token 激活140亿，预训练使用33.5万亿 token，预训练上下文最高128K，微调与推理支持最长100万 token。

百度称，该模型在知识、推理、数学、代码、多语言和长上下文等基准上取得同尺寸模型 SOTA，超过 DeepSeek-V4-Flash-Base、Hy3-preview-Base、MiMo-V2.5-Base；这些结果来自百度提供的评测口径。

架构上，模型采用 Latent-Gated Sparse Attention、Multi-Router Latent MoE 和 ECHO 训练目标；百度称低秩门控注意力使门控投影权重参数减少75%。

According to QbitAI, Baidu open-sourced the base model ERNIE 5.5 Flash Base on Hugging Face on November 5. The model uses a MoE architecture, with 280 billion total parameters, 14 billion activated per token, pretraining on 33.5 trillion tokens, a pretraining context of up to 128K, and support for up to 1 million tokens in fine-tuning and inference.

据量子位报道，百度11月5日在 Hugging Face 开源基座模型文心5.5 Flash Base（ERNIE 5.5 Flash Base）。模型采用 MoE 架构，总参数2800亿，每个 token 激活140亿，预训练使用33.5万亿 token，预训练上下文最高128K，微调与推理支持最长100万 token。

Baidu says the model achieves SOTA among models of the same size on benchmarks covering knowledge, reasoning, math, code, multilingual capabilities and long context, surpassing DeepSeek-V4-Flash-Base, Hy3-preview-Base and MiMo-V2.5-Base; these results come from the evaluation methodology provided by Baidu.

百度称，该模型在知识、推理、数学、代码、多语言和长上下文等基准上取得同尺寸模型 SOTA，超过 DeepSeek-V4-Flash-Base、Hy3-preview-Base、MiMo-V2.5-Base；这些结果来自百度提供的评测口径。

In terms of architecture, the model uses Latent-Gated Sparse Attention, Multi-Router Latent MoE and the ECHO training objective; Baidu says low-rank gated attention reduces gating projection weight parameters by 75%.

架构上，模型采用 Latent-Gated Sparse Attention、Multi-Router Latent MoE 和 ECHO 训练目标；百度称低秩门控注意力使门控投影权重参数减少75%。

NVIDIA Releases Four Open-Weight Cosmos 3 Models

NVIDIA 发布 Cosmos 3 四个开放权重模型

11月06日 03:35重要可靠性 A

NVIDIA 在 Hugging Face 博客发布 Cosmos 3 系列四个开放权重 checkpoint，用于生成交互式世界模拟和多传感器、多视角驾驶场景；四个模型均为 Cosmos 3 Nano 的后训练版本，有16B可训练参数。

这些模型使用 OpenMDW1.1 许可，允许商业和非商业使用；其中 Transfer-Auto 支持最多11个相机视角和联合 RGB-LiDAR 生成，Sim-Auto 是面向流式生成的变体。

NVIDIA 同时表示，后续仍需衡量这些模型在策略学习与评估中的可靠支持范围，并理解其局限。

In a Hugging Face blog post, NVIDIA released four open-weight checkpoints in the Cosmos 3 series for generating interactive world simulations and multi-sensor, multi-view driving scenes; all four models are post-trained versions of Cosmos 3 Nano and have 16B trainable parameters.

NVIDIA 在 Hugging Face 博客发布 Cosmos 3 系列四个开放权重 checkpoint，用于生成交互式世界模拟和多传感器、多视角驾驶场景；四个模型均为 Cosmos 3 Nano 的后训练版本，有16B可训练参数。

These models use the OpenMDW1.1 license, which permits commercial and non-commercial use; Transfer-Auto supports up to 11 camera views and joint RGB-LiDAR generation, while Sim-Auto is a variant designed for streaming generation.

这些模型使用 OpenMDW1.1 许可，允许商业和非商业使用；其中 Transfer-Auto 支持最多11个相机视角和联合 RGB-LiDAR 生成，Sim-Auto 是面向流式生成的变体。

NVIDIA also said that going forward it will still be necessary to assess the reliable scope of support these models provide in policy learning and evaluation and to understand their limitations.

NVIDIA 同时表示，后续仍需衡量这些模型在策略学习与评估中的可靠支持范围，并理解其局限。

Taobao's MNN Open-Sources 0.3B On-Device Model, Achieving About 350 Tokens/s Offline Decoding on iPhone 18 Pro

淘宝 MNN 开源0.3B端侧模型，iPhone 18 Pro 离线解码约350 token/s

11月06日 11:50重要可靠性 B

据IT之家报道，淘宝 MNN 团队发布并开源 MNN-Pocket-0.3B，约3亿参数，重点支持中英文，INT4 部署文件体积173MB。

团队称，在 iPhone 18 Pro 上通过 MNN 推理引擎完全离线运行，平均解码约350 token/s；在 iPad Pro M5、Metal 后端、512 token 配置下，峰值 Metal 驻留内存较加载前增加228MB，部署体积和峰值内存增量分别比 Qwen3-0.6B 少约49%和47%。

技术报告评测中，英文 IFEval 得分73.20，中文 IFEval-zh 74.59，11项评测平均50.00。上述数据由团队公布。

According to IT Home, the Taobao MNN team released and open-sourced MNN-Pocket-0.3B, which has about 300 million parameters, focuses on Chinese and English support, and has an INT4 deployment file size of 173 MB.

据IT之家报道，淘宝 MNN 团队发布并开源 MNN-Pocket-0.3B，约3亿参数，重点支持中英文，INT4 部署文件体积173MB。

The team said that on the iPhone 18 Pro it runs completely offline through the MNN inference engine, with average decoding at about 350 tokens/s; on the iPad Pro M5, with the Metal backend and a 512-token configuration, peak Metal resident memory increased by 228 MB compared with before loading, and the deployment size and peak memory increase were about 49% and 47% lower than those of Qwen3-0.6B, respectively.

团队称，在 iPhone 18 Pro 上通过 MNN 推理引擎完全离线运行，平均解码约350 token/s；在 iPad Pro M5、Metal 后端、512 token 配置下，峰值 Metal 驻留内存较加载前增加228MB，部署体积和峰值内存增量分别比 Qwen3-0.6B 少约49%和47%。

In the evaluations in the technical report, it scored 73.20 on English IFEval, 74.59 on Chinese IFEval-zh, and an average of 50.00 across 11 evaluations. The above figures were published by the team.

技术报告评测中，英文 IFEval 得分73.20，中文 IFEval-zh 74.59，11项评测平均50.00。上述数据由团队公布。

NVIDIA Says Vera CPU Balances Throughput and Energy Efficiency in AI Agent Workloads

NVIDIA 称 Vera CPU 在 AI agent 负载中兼顾吞吐与能效

11月06日 04:00重要可靠性 A

NVIDIA 在博客中称，Vera CPU 在100兆瓦数据中心比较中，单颗性能优于最快 x86 CPU 和最能效 x86 CPU；每瓦支持的 AI agent 数量比最快 x86 多1.6倍，agent 速度比最能效 x86 高2倍。

NVIDIA 还列出早期客户数据：Perplexity 的 agentic coding 任务快1.5倍，DeepInfra 的 agent 编排最高快2.2倍。上述数字均来自 NVIDIA 公布的对比。

NVIDIA said in a blog post that in a 100-megawatt data center comparison, the Vera CPU's per-chip performance exceeded that of both the fastest x86 CPU and the most energy-efficient x86 CPU; the number of AI agents supported per watt was 1.6 times more than that of the fastest x86, and agent speed was 2 times higher than that of the most energy-efficient x86.

NVIDIA 在博客中称，Vera CPU 在100兆瓦数据中心比较中，单颗性能优于最快 x86 CPU 和最能效 x86 CPU；每瓦支持的 AI agent 数量比最快 x86 多1.6倍，agent 速度比最能效 x86 高2倍。

NVIDIA also listed early customer data: Perplexity's agentic coding tasks were 1.5 times faster, and DeepInfra's agent orchestration was up to 2.2 times faster. All these figures came from comparisons published by NVIDIA.

NVIDIA 还列出早期客户数据：Perplexity 的 agentic coding 任务快1.5倍，DeepInfra 的 agent 编排最高快2.2倍。上述数字均来自 NVIDIA 公布的对比。
