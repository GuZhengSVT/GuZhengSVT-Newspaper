OpenAI Launches ChatGPT Wallet for Dots Agents, With Per-Purchase Approval Required

OpenAI推出ChatGPT Wallet，Dots代理可代购但需逐笔批准

11月14日 04:45重大可靠性 B

据The Verge报道，OpenAI推出面向Dots代理的ChatGPT Wallet，11月13日起向美国18岁以上的ChatGPT Pro订阅用户逐步开放。用户需使用美国账单地址和符合条件的美国发行美国运通、Chase、万事达或Visa卡。

添加卡片后，Dots代理可依据用户提示选购商品，但每次结账前都要用户确认，并通过Face ID或指纹等生物验证；支付时用支付令牌替代实际卡号，商户和代理不会获得完整卡信息。

OpenAI称未来将允许用户设置消费限额、购买类别或时段，并预先批准符合条件的购买，让代理完全代购。部分零售商已限制或屏蔽AI代理购物，OpenAI表示需要网站和支付风控系统识别代理发起的合法交易。

According to The Verge, OpenAI has launched ChatGPT Wallet for Dots agents, gradually opening it from November 13 to US ChatGPT Pro subscribers aged 18 and over. Users need a US billing address and an eligible US-issued American Express, Chase, Mastercard or Visa card.

据The Verge报道，OpenAI推出面向Dots代理的ChatGPT Wallet，11月13日起向美国18岁以上的ChatGPT Pro订阅用户逐步开放。用户需使用美国账单地址和符合条件的美国发行美国运通、Chase、万事达或Visa卡。

After a card is added, Dots agents can select products based on user prompts, but each checkout requires user confirmation through biometric authentication such as Face ID or a fingerprint; payments use a payment token instead of the actual card number, so merchants and agents do not receive full card information.

添加卡片后，Dots代理可依据用户提示选购商品，但每次结账前都要用户确认，并通过Face ID或指纹等生物验证；支付时用支付令牌替代实际卡号，商户和代理不会获得完整卡信息。

OpenAI says it will in the future allow users to set spending limits, purchase categories or time windows, and pre-approve eligible purchases so that agents can complete purchases entirely on their behalf. Some retailers have restricted or blocked AI agent shopping, and OpenAI says websites and payment risk-control systems need to identify legitimate transactions initiated by agents.

OpenAI称未来将允许用户设置消费限额、购买类别或时段，并预先批准符合条件的购买，让代理完全代购。部分零售商已限制或屏蔽AI代理购物，OpenAI表示需要网站和支付风控系统识别代理发起的合法交易。

llama.cpp Releases v1.0.0, Introduces Semantic Versioning

llama.cpp发布v1.0.0，引入语义版本管理

11月13日 22:05重要可靠性 A

ggml-org于11月13日发布llama.cpp v1.0.0和ggml v1.0.0。项目称这是面向下游开发者的稳定性里程碑，今后llama.cpp与ggml的公共C API出现不兼容变更时提升主版本号，向后兼容的功能、后端或模型支持提升次版本号，无API变化的修复提升补丁号。

llama.cpp定位为跨平台本地AI推理框架，通过量化和专用后端在消费级设备到企业服务器上运行多模态大模型。项目称目前支持150多种架构变体和主流投机解码方法，并为Linux、macOS、Windows、Android、iOS及多个包管理器提供预发布构件。

ggml-org released llama.cpp v1.0.0 and ggml v1.0.0 on November 13. The project calls this a stability milestone for downstream developers: future incompatible changes to the public C APIs of llama.cpp and ggml will increment the major version number, backward-compatible features, backends or model support will increment the minor version number, and fixes without API changes will increment the patch number.

ggml-org于11月13日发布llama.cpp v1.0.0和ggml v1.0.0。项目称这是面向下游开发者的稳定性里程碑，今后llama.cpp与ggml的公共C API出现不兼容变更时提升主版本号，向后兼容的功能、后端或模型支持提升次版本号，无API变化的修复提升补丁号。

llama.cpp is positioned as a cross-platform local AI inference framework that runs multimodal large models from consumer devices to enterprise servers through quantization and specialized backends. The project says it currently supports more than 150 architecture variants and mainstream speculative decoding methods, and provides pre-release artifacts for Linux, macOS, Windows, Android, iOS and several package managers.
